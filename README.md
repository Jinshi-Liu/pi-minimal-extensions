# Pi Minimal Extensions

基于 [Pi 官方示例](https://github.com/earendil-works/pi/tree/v1.4.0/packages/coding-agent/examples/extensions) 实现的两个扩展：Plan Mode 和 Subagent。

## 安装

分别安装：

```sh
pi install npm:pi-minimal-plan
pi install npm:pi-minimal-subagent
```

或从 GitHub 一次安装两个：

```sh
pi install git:github.com/Jinshi-Liu/pi-minimal-extensions
```

安装后输入 `/reload`。选择一种安装方式即可。
